# Simulated Task for Edge Device Offloading
Simulated task for experiments with edge device task offloading on O-RAN environments.
Runs a hashing function with a given size, with the idea of being CPU-intensive. 
Afterward, sends a callback to the given address with the execution time and other data.

The built image and be found and used on [Docker Hub](https://hub.docker.com/repository/docker/rafaelrs94/xapp-mec/tags/task-sim/).

Used mainly by the [Edge Device Simulator](https://github.com/RafaelRochaS/edge-device-simulator).
